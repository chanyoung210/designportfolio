# 포트폴리오 웹사이트 디자인 — "일상속의 비트"

## 목표

기존 UX 포트폴리오 결과물만으로는 임팩트가 약하다고 판단, 웹사이트 자체의 화려한 인터랙션과 브랜딩("선물 포장지")으로 인상을 강화하는 것이 핵심 목표. 최적화(성능)를 인터랙션 화려함과 동등한 우선순위로 다룬다.

## 정보 구조 (원페이지, 위→아래)

1. **인트로** — 블랙 또는 눈이 편한 그린 배경. 화면 중앙에 "비트(맥박)"가 점점 강하게 요동치는 펄스 연출.
2. **폴드 전환** — 화면이 위로 접히는 트랜지션으로 인트로 → 히어로 전환.
3. **히어로** — 흰색 원 라인 3개(CX / BX / UX)가 겹쳐진 벤다이어그램 형태. 스크롤 진행에 따라 원이 하나씩 커지며 사라지고, 최종적으로 "USER"로 귀결되는 메시지 전달 ("어떤 디자인을 하든 결국 유저를 위한다"). 애플 제품소개 페이지처럼 이 섹션은 스크롤 중 화면에 **핀 고정**되어, 원 3개가 순차적으로 사라지는 애니메이션이 다 끝나야 다음 섹션(프로젝트 리스트)으로 스크롤이 넘어간다.
4. **프로젝트 리스트** — 비대칭 그리드. 아이템 클릭 시 모달/풀스크린 오버레이로 상세 콘텐츠가 페이드 인/아웃되며 열림. `history.pushState`로 URL 갱신(새로고침해도 딥링크 유지, 실제 페이지 이동 없음).
5. **자기소개(About)** — 하단부.
6. **푸터** — 연락처 이메일.

## 인터랙션 & 비주얼 디자인

- **킨네틱 타이포그래피**: 섹션 제목/프로젝트명이 스크롤에 맞춰 글자 단위로 등장(SplitText 방식), 스크롤 진행률에 따라 자간/크기 변화.
- **비대칭 레이아웃**: 프로젝트 리스트는 균일 격자 대신 이미지·텍스트 블록이 겹치거나 화면 밖으로 걸치는 배치. 오버사이즈 텍스트를 포인트로 사용.
- **공간감(깊이) 연출**: WebGL 없이 CSS만으로 구현.
  - 패럴렉스 레이어링(배경/중간/전경이 다른 속도로 스크롤)
  - `perspective` + `translateZ` 기반 CSS 3D transform (GPU 가속, 가벼움)
  - 블러/스케일 대비로 카메라 심도 효과 흉내
- **글래스모피즘**: 프로젝트 카드·모달 패널에 `backdrop-filter: blur()` 기반 유리 질감. 다크 배경 위 대비로 활용.
- **모양 변화 연출**: 3D 모델링/WebGL 대신 SVG/Canvas 2D 기반 모션으로 구현 (원의 확대·축소·페이드, 클리핑 등).

## 기술 스택

- **프레임워크**: Vite + React (SPA, 클라이언트 사이드 렌더링만 필요, SSR/라우팅 불필요)
- **애니메이션**: GSAP (ScrollTrigger 중심), Three.js/WebGL 미사용
- **스타일링**: CSS (backdrop-filter, 3D transform 활용)
- **배포**: GitHub 레포 → Vercel 연결, push 시 자동배포

## 최적화 전략

- `prefers-reduced-motion` 대응(모션 최소화 옵션 제공)
- 이미지 lazy-loading
- GSAP 등 애니메이션 관련 코드는 필요 시점에 코드 스플리팅으로 로드
- `backdrop-filter` 레이어 수를 제한해 저사양 기기 GPU 부담 최소화

## 범위 밖 (Out of scope)

- Three.js/WebGL 기반 실사 3D 렌더링 (이번 버전에서는 CSS 3D transform으로 대체)
- 이미지 시퀀스 스크러빙(애플 맥북/아이폰 360도 회전 연출) — 최적화 부담이 크고 회전시킬 콘텐츠(3D 렌더/촬영본)도 없어 제외. 핀 고정 스크롤만 채택.
- 다국어 지원
- CMS 연동 (콘텐츠는 코드 내 하드코딩)
